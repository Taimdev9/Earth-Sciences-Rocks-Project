مشروع تفاعلي ثلاثي الأبعاد (3D) لدرس المعادن في مادة علوم الأرض. تم تطوير هذا الموقع كبديل مبتكر وعصري للعروض التقديمية التقليدية (البوربوينت)، ليوفر تجربة تعليمية بصرية ممتعة وممتعة.

## ✨ مميزات المشروع
*   **تصميم بسيط وأنيق (Minimalist):** يعتمد على الوضع الداكن (Dark Mode) مع لمسات نيون مريحة للعين.
*   **مجسمات 3D تفاعلية:** استخدام مكتبة `Three.js` لعرض بلورات ومعادن مجسمة تتأثر بحركة الماوس.
*   **شاشة تحميل احترافية:** محاكاة لشاشات تحميل التطبيقات الحديثة.
*   **6 أقسام تعليمية:** تغطي كامل محتوى الدرس (المفهوم، الأنظمة البلورية، التناظر، الخصائص الفيزيائية، مقياس موس).
*   **متجاوب:** يعمل بكفاءة على مختلف أحجام الشاشات.

## 🛠️ التقنيات المستخدمة
*   **HTML5:** لبناء هيكل الموقع.
*   **CSS3:** للتصميم، التأثيرات الحركية، والوضع الداكن.
*   **JavaScript (Vanilla):** لبرمجة التفاعلات وحركة العناصر.
*   **Three.js:** المحرك الأساسي لرسم وعرض العناصر ثلاثية الأبعاد في المتصفح.
*   **GitHub Pages:** لاستضافة الموقع ونشره.

## 🚀 كيفية التشغيل محلياً
إذا أردت تشغيل المشروع على جهازك، اتبع الخطوات التالية:
1. قم بتحميل المشروع (Clone) أو تحميله كملف ZIP.
2. افتح ملف `index.html` في أي متصفح حديث (مثل Chrome أو Edge).
3. استمتع بالاستكشاف!
