# Earth-Sciences-Rocks-Project
Earth-Sciences-Rocks-Project هو موقع ويب تفاعلي ثلاثي الأبعاد لدرس المعادن، صُمم كبديل مبتكر للبوربوينت. تم تطويره بواسطة Taimdev9 بإشراف الأستاذة ضحى. يعتمد على تقنيات HTML/CSS/JS ومكتبة Three.js لعرض مجسمات 3D للبلورات والصخور عبر 6 أقسام مميزة، مع شاشة تحميل وتصميم داكن بسيط. مستضاف على GitHub Pages.
